\# STM32 Smart Monitor System



A smart monitoring system based on STM32F103C8T6.



\## Features



\- Ultrasonic distance measurement

\- Light intensity detection

\- OLED display

\- Buzzer alarm

\- SPI Flash driver development



\## Hardware



\- STM32F103C8T6

\- HC-SR04 ultrasonic sensor

\- OLED

\- LDR module

\- W25Qxx SPI Flash



\## Software



\- STM32CubeMX

\- Keil MDK

\- STM32 HAL Library

\- C language
